# Preguntas Frecuentes

## ¿Esta API es oficial?

No. Esta documentación está creada por fans, pero no es una API oficial ni afiliada directamente.

## ¿Los datos se actualizan automáticamente?

No. Si deseas mantener datos actualizados, debes consultar frecuentemente la versión más reciente

## ¿Puedo usar esto para un proyecto personal?

Sí. Puedes consumir los endpoints y mostrar información de campeones en apps personales, educativas o pruebas de concepto.
