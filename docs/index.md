# League of Legends Champs API

Bienvenido a la documentación de la **LoL Champs API**, una API educativa. Aquí podrás consultar la lista de campeones, detalles de cada uno, y cómo integrarlos en tus proyectos.

## ¿Qué ofrece esta API?

- Consulta de campeones y sus estadísticas.
- Uso de ejemplos reales con `curl`, `fetch`, y `Python`.

Para comenzar, visita nuestra [guía de uso](guia/usage.md).

!!! tip
    Este proyecto es ideal para prácticas de integración de APIs REST, interfaces en React, o sistemas de búsqueda de campeones.
